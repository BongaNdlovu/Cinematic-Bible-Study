# 6. User interface

**Last verified:** 12 November 2026

## Design approach

- **One look across pages:** a dark, museum-like style with gold accents. Shared stylesheets (`cinema.css`, `terms.css`, `consent.css`, `desk.css`) give every page the same transitions, terms gate, consent banner and message desk.
- **Plain CSS per page:** each page has its own stylesheet (see [Project structure](03-project-structure.md#pages-and-their-scripts)). The study desk also uses Tailwind, compiled ahead of time into `css/study-tailwind.css` (`npm run build:tailwind`). Nothing is compiled in the browser.
- **No UI framework:** components are plain DOM code, each owned by one script.

## Accessibility

| Practice | Where |
|---|---|
| `lang="en"` on every page | All HTML files |
| Landmarks: `header`, `main`, `nav` with `aria-label`, `footer` | For example `study.html`, `index.html` |
| Live regions for loaders, toasts, the sitting spine and audio checkpoints | `index.html`, `study.html` |
| Dialogs trap focus and close with Escape. One Escape closes one layer. | Focus trap: `task-flow.js`, `term-overlay.js`, `mindmap.js`. Escape layering also in `desk.js`. |
| Keyboard answers in the question dialog (letter or number keys) | `js/study/task-flow.js` |
| Reduced motion honoured in 17 stylesheets and in the animating scripts | See [Performance](05-performance.md#6-motion-and-battery) |
| Broken images fall back gracefully | `js/shared/errors.js` |

**Not checked in this pass:** a full screen-reader walkthrough, colour-contrast measurements, and keyboard-only use of the 3D scenes.

## UI rules worth keeping

- A late server reply must never change a screen the reader has already left. Guard every async callback with a ticket or generation check. The quiz, task-flow, report builder and map flight all use this pattern.
- Each layer owns its own Escape. A layer that is not on top must not react.
- Destructive buttons ask twice ("Remove for you?"). After a failure they go back to their normal state.
- Never show a "write a new one" form when the site could not check whether one already exists.
